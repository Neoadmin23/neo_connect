# Version 1.2.0 Release Notes

## Highlights

- Central Magento configuration for dedicated API users, permissions and encrypted credential management.
- Complete-order invoice creation and native submission, with shared order deduplication across configured users.
- Correlated activity history, filtered reports and configuration/workspace navigation.
- Architecture, developer/contributor guides, Postman acceptance suite and versioned upgrade notes.

## Verification

- 46 unit/mock, 23 invoice HTTP/database and 25 management HTTP/database tests passed locally.
- Actual Newman run: 12 requests, 34 assertions, no failures.
- Customer deployment, browser acceptance and customer-specific workflows/e-invoicing acceptance remain pending.
