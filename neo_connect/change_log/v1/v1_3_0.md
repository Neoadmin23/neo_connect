# Version 1.3.0 Release Notes

## Highlights

- Unified Magento client setup, user access, credential delivery and monitoring page.
- Disabled-by-default onboarding with company/master/custom-field checks and tax-row cost-center defaults.
- Downloadable Postman collection and optional private environment with API/HMAC credentials.
- Filtered charts, all-row aggregates, paged trace tables and report/invoice navigation.
- Documented PowerTire sandbox changes and security acceptance, including the hosted 429 response limitation.

## Verification

- 52 unit/mock cases and 12 new isolated dashboard HTTP cases passed.
- Generated HMAC Postman validation: 2 requests, 4 assertions, zero failures.
- Browser collection/private-environment downloads verified.
- Customer sandbox dashboard deployment and proxy response preservation remain pending.
